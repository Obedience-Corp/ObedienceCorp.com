Every AI coding tool today operates in isolation. One agent, one terminal, one person watching. That doesn't scale.

Running 10 agents across 5 projects requires 10 terminals, constant context switching, and no unified view of what's happening. There's no metering, no security boundaries, no audit trail.

Obey solves this by providing the runtime layer: a daemon that manages agent sessions, enforces campaign-scoped boundaries, meters token usage, and streams activity to wherever you need it.

The model is smart enough. The infrastructure to use it at scale is what's missing.

**Obey is that infrastructure.**
